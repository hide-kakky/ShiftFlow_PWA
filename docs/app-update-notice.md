# アプリ本体の更新案内
- `sw.js` と `app-config.js` のバージョンは `npm run bump:version -- X.Y.Z` で揃える。
- ブラウザ内の稼働中サービスワーカーが返す版が画面の版より新しい場合、編集中でないホームの中央に「新しいバージョン（X）を利用できます。」と「今すぐ更新」を15秒表示する。同じ版で繰り返し出さない。更新確認に業務API、D1、プッシュ通知は使わない。
- 押したウィンドウだけを再読み込みし、セッションや個別の下書きを消去しない。キャッシュ全消去・再ログインへ誘導する以前のメニュー項目は提供しない。通常のサインアウトは従来どおり。押下後、新しい画面と稼働サービスワーカーの版が揃えば中央の案内とは別に、画面上部に「更新されました」のトーストを約3秒表示して消す。
- 2.2.10以前から今回の新方式へ移行する際、開いたままの旧画面は新しいボタンを表示できない。入力を終え、通常の再読み込み、またはホーム画面アプリの閉じ直しで移行する。
- 2.3.0は更新ボタンの操作記録を残さない。2.3.10・2.3.11への移行時のみ、同じタブの初回再読み込みで稼働版を確認できた場合、「最新版 X を読み込みました」と表示する。
- 更新案内には既存のモダン確認画面と同じコンテナ、テーマ色、標準の主ボタンを使用する。スマホではボタンを横幅いっぱいに広げ、完了トーストは同じカード面にチェック印を添える。
- 更新案内とトーストの表示は専用処理だけが管理し、ログイン時の一括表示の対象にしない。
- 公開前に、旧版からの最初の移行、新方式から次の版への遷移、別タブでの編集中の申し送り、ログイン維持、iPhoneホーム画面アプリを確認する。ロールバックは直前のCloudflare Pages配布を選択する。
